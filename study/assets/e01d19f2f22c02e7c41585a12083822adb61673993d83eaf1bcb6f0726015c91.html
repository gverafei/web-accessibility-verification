Frequently asked questions

Is the Brave Browser safe?

Brave blocks privacy-invasive ads and trackers, blocks third-party data storage, helps protect against browser fingerprinting, and upgrades webpages to secure HTTPS connections where possible. These protections are on by default.

Brave is built on the open-source Chromium Web core. Learn more about Brave privacy features.

How do I download and install Brave?

Brave is available for Windows, macOS, Linux, Android, and iOS. Get started with Brave for desktop, download it for Android, or get it for iOS.

Does Brave have a VPN?

Yes. Brave Firewall + VPN protects connections across your entire device, including outside the Brave Browser. One subscription covers up to five devices.

Does Brave block YouTube ads?

Brave can block ads on video sites like YouTube, including on-page, pre-roll, and mid-roll ads. Learn more about Brave’s YouTube ad blocking.

What is Brave Search?

Brave Search is a private, independent search engine with its own index of the Web and AI answer features. It does not profile you. It’s available in any browser at search.brave.com. Learn more about Brave Search.

Is Brave free?

Yes, Brave is free to use. Download it for desktop, Android, or iOS. Brave also offers subscription-based features, including Brave Talk Premium and Brave Firewall + VPN.

How does Brave compare to Chrome?

Brave blocks privacy-invading ads and trackers by default, so there is less content to load on webpages. See how Brave compares with Chrome.

Is Brave open source?

Yes. Brave is built on the open-source Chromium Web core, and Brave’s client code is released under the Mozilla Public License 2.0.
