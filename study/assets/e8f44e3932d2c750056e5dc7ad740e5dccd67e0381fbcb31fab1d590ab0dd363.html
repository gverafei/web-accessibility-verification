Good to know

Frequently asked questions

How do I register a domain name?

Choose a name and a domain ending, such as .net, .fr, or .org. A domain name is registered for a period of 1 to 9 years and can be renewed. Use the domain search tool to check availability.

Who does a domain name belong to?

Once registered, a domain name is associated with an owner contact, who holds it for the registration period. If a name is unavailable, someone else has already registered it. You can look for information with the Whois service or search for alternatives.

What is a web host?

A web host makes data storage and web servers available to website owners. Hosting providers install, secure, and maintain servers and the technical infrastructure used to make websites available online.

Which web hosting solution should I choose?

The right solution depends on your project and technical needs. Gandi offers WordPress hosting, PrestaShop hosting, VPS hosting, and other web hosting solutions.
