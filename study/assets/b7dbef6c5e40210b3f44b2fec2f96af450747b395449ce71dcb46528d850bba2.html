PHP 8.6.0 RC3 available for testing

08 Oct 2026

The PHP team is pleased to announce the first release candidate of PHP 8.6.0, RC3. This continues the PHP 8.6 release cycle, whose rough outline is specified in the PHP Wiki.

Source downloads of PHP 8.6.0 RC3 are available on the download page.

Please carefully test this version and report any issues found in the GitHub Issues.

Please DO NOT use this version in production, it is an early test version.

For more information on the new features and other changes, you can read the NEWS file, or the UPGRADING file for a complete list of upgrading notes.

The next release will be RC4, planned for 22 October 2026.

PHP 8.6.0 RC2 available for testing

24 Sep 2026
Read the full RC2 announcement

The PHP team is pleased to announce the first release candidate of PHP 8.6.0, RC2. It is not a typo: a mistake was made while packaging RC1, so RC2 was released instead. For a full explanation, see this blog post. This continues the PHP 8.6 release cycle, whose rough outline is specified in the PHP Wiki.

Source downloads of PHP 8.6.0 RC2 are available on the download page.

Please carefully test this version and report any issues found in the GitHub Issues.

Please DO NOT use this version in production, it is an early test version.

The next release will be RC3, planned for 8 October 2026.

Last Call for the State of PHP Survey

25 Aug 2026

The State of PHP survey is still open, but not for much longer. It asks how PHP is working for you and takes around 15 minutes. The survey is run by The PHP Foundation in partnership with PhpStorm by JetBrains.
