Latest news

PHP 8.6.0 RC3 available for testing

08 Oct 2026

The PHP team is pleased to announce the first release candidate of PHP 8.6.0, RC3. This continues the PHP 8.6 release cycle, whose rough outline is specified in the PHP Wiki.

Source downloads of PHP 8.6.0 RC3 are available from the PHP 8.6.0 RC3 download page. Please carefully test this version and report any issues in GitHub Issues.

Please do not use this version in production; it is an early test version.

Read the NEWS file for new features and changes, or the UPGRADING file for upgrading notes. The next release is RC4, planned for 22 October 2026.

Last call for the State of PHP survey

The State of PHP survey asks how PHP is working for you, what you build with, what is painful, and what PHP should focus on next. It takes around 15 minutes.

The survey is run by The PHP Foundation in partnership with PhpStorm by JetBrains. Aggregated results and an anonymized raw dataset are planned for publication later in 2026.
