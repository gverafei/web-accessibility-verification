Frequently asked questions

Learn the basics of domains and web hosting.

How do I purchase a domain name?

Choose a name and a domain ending, then register it for a specific period between 1 and 9 years. You can check availability with the domain search tool. If available, you can add it to your cart. Learn more about registering a domain name.

Who does a domain name belong to?

Registries manage particular domain endings, while accredited registrars such as Gandi sell registrations to end users. Once registered, a domain name is associated with an Owner contact for the registration period. If a name is unavailable, someone else has already registered it. You can check with the Whois service or look for alternatives with the suggestion tool.

How do I recover or re-purchase a domain name?

You can look up registration information using Whois and try to contact the current owner to make an offer. Contact information may not be public or up to date, including because of privacy regulations.

What is a web host?

A web host makes data storage and web servers available to website owners. Hosting providers install, secure, and maintain the server infrastructure used to make a website's content available online.

Which web host should I choose?

The right hosting depends on what you are building and the level of expertise and resources you need. Gandi offers hosting for blogs, business hosting, and VPS hosting, among other options. Explore web hosting solutions.
