Software For The Public Good¶

The Apache® Software Foundation (ASF) provides software for the public good, guided by community over code. Like the enduring oak tree, our projects thrive through the contributions of thousands worldwide.

Upcoming Events¶

Fluss Forward London¶

London, UK¶

September 22-23, 2026

Apache Fluss is open-source, lakehouse-native streaming storage that makes your data lakehouse truly real-time. Fluss Forward is where the community that builds and runs it comes together. This isn't a vendor showcase. It's a community event.

See Event

Lakehouse Day¶

Glasgow, UK¶

October 10-11, 2026

LakehLakehouse Day 2026 is an all-day, multi-track conference co-located with Community Over Code Glasgow 2026. Taking place on October 10, the event is dedicated to all things related to open lakehouse technologies under the Apache Software Foundation (ASF) umbrella, with content supporting Apache Iceberg™, Apache Hudi, Apache Parquet™, Apache Gravitino, Apache Polaris™, and more.

See Event

Community Over Code Glasgow 2026¶

Glasgow, Scotland, UK¶

October 11-14, 2026

Community Over Code Glasgow 2026 features four in-person days of sessions at the Hilton Glasgow for ASF members, committers, and open source developers from around the world, focusing on Search, Big Data, Internet of Things, Community, Geospatial, Financial Tech, and many other topics.

See Event

Community Over Code Sydney 2026¶

Sydney, Australia¶

November 18-19, 2026

Community Over Code Sydney 2026 is a two-day intimate conference running two streams of diverse and interesting talks.
