PHP 8.6.0 RC3 available for testing

08 Oct 2026

The PHP team is pleased to announce the release candidate of PHP 8.6.0, RC3. This continues the PHP 8.6 release cycle, whose rough outline is specified in the PHP Wiki.

Source downloads of PHP 8.6.0 RC3 are available on the download page. Please carefully test this version and report any issues found in the GitHub Issues.

Please do not use this version in production; it is an early test version.

For information on new features and other changes, read the NEWS file or the UPGRADING file. The next release will be RC4, planned for 22 October 2026.

Release signatures are available in the manifest or on the pre-release builds page.
