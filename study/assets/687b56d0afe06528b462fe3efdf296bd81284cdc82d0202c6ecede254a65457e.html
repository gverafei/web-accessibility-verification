Other tools

Download test files

curl / wget

Static files from 1 MiB to 10 GiB, downloaded to /dev/null so nothing is written to disk.

curl -o /dev/null https://lil1-rbx.speedtest.network.ovh.net/files/100Mb.dat

Other test files with different size are available here.

iperf3 server

iperf3

TCP throughput from the command line. -R measures download (server to you); drop it to measure upload.

iperf3 -c lil1-rbx.speedtest.network.ovh.net -p 5201 -R

ports 5201–5210, one test at a time per port: if it says "busy", try another

Network diagnostics

diagnostics

From the command line, no account or install required.

mtr -rwc 10 lil1-rbx.speedtest.network.ovh.net
ping -c 10 lil1-rbx.speedtest.network.ovh.net
traceroute lil1-rbx.speedtest.network.ovh.net
