nginx

nginx (“engine x”) is an HTTP web server, reverse proxy, content cache, load balancer, TCP/UDP proxy server, and mail proxy server. Originally written by Igor Sysoev and distributed under the 2-clause BSD License. Enterprise distributions, commercial support and training are available from F5, Inc.

Older news
  1. 2026-10-14

    nginx-1.30.6 stable and nginx-1.31.7 mainline versions have been released, with fixes for:

    • Buffer overflow when using alias with rewrite (CVE-2026-15176).
    • Buffer overflow when evaluating string expressions with variables (CVE-2026-93479).
    • Request body injection in HTTP/3 (CVE-2026-95101).
    • Session forgery when using TLS session ticket key rotation (CVE-2026-97629).
    • Use-after-free when using ngx_http_ssi_module with AIO (CVE-2026-97205).
  2. 2026-10-14

    njs-1.0.2 version has been released, with fixes for:

    • Memory exhaustion when parsing malformed XML (CVE-2026-101025).
    • Inconsistent XML attribute values affecting signed XML validation (CVE-2026-101019).
  3. 2026-09-15

    nginx-1.30.5 stable and nginx-1.31.6 mainline versions have been released, with a fix for buffer overflow vulnerability when using ngx_http_v3_module (CVE-2026-90439).

  4. 2026-09-02

    nginx-1.31.5 mainline version has been released, featuring the control API, predicate locations, and the ngx_http_json_module.
