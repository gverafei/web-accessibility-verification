Good to know

Frequently asked questions

Is the Brave Browser safe?

Brave blocks privacy-invasive ads and trackers, blocks third-party data storage, protects against browser fingerprinting, and upgrades webpages to secure HTTPS connections where possible. These protections are on by default. Learn about Brave privacy features.

How do I download and install Brave?

Brave is available for Windows, macOS, Linux, Android, and iOS. Download Brave for desktop, get it for Android, or get it for iOS.

Does Brave have a VPN?

Brave Firewall + VPN is a subscription service designed to protect connections across your device, including outside the Brave Browser. Learn about Firewall + VPN.

Does Brave block YouTube ads?

Brave can block ads on video sites such as YouTube, including on-page and video ads. Learn more about Brave’s YouTube ad blocking.

What is Brave Search?

Brave Search is a private, independent search engine with its own index of the Web. Brave says it does not profile users or collect personal data for sharing or sale. Learn more about Brave Search.

Is Brave free and open source?

Yes, Brave is free to use. The browser is built on the open-source Chromium Web core, and Brave’s client code is released under the Mozilla Public License 2.0. View the Brave Browser source code.

How does Brave compare to Chrome?

Brave blocks privacy-invading ads and trackers by default, so there is less content to load on webpages. Read the Brave vs Chrome comparison.
