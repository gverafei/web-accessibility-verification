Frequently asked questions

How do I purchase a domain name?

When you start working on the creation of your website or online store, the first thing to do is to choose and register a domain name. You can't purchase a domain name per se. It consists of whichever string of text you choose, plus a domain ending (.net, .fr, .org, etc.) that you register for a period between 1 and 9 years (renewable indefinitely).

You can check whether the domain name you want is available with our search tool. If it's available, add it to your cart.

Who does a domain name belong to?

Registries manage particular domain endings (.net, .fr, .com, .org, etc.) and sell domain names with those endings. Registrars like Gandi are accredited by each registry so they can sell domain names to end users. Once registered, a domain name is associated with an Owner contact, who becomes its "holder" for a particular length of time.

If a name shows as unavailable in the results of a search, someone else has already registered it. You can check the owner with our whois service or look for alternatives with our suggestion tool.

How do I recover or re-purchase a domain name?

If the domain name you want is already taken, you can find the current owner using the Whois and make an offer. The Whois is the directory of technical and contact information for domain names, including the registrar, registration date, expiration date, and last updated date.

The Whois is not always up to date, and GDPR prevents registrars from publishing full contact details for private individuals without consent. You can try contacting the organization listed, or the contact page of the website associated with the domain name, but nothing is certain.

What is a web host?

A web host (or hosting provider) is a service provider that makes data storage and web servers available to website admins or owners. The stored data includes the elements that will be made available on the web and viewed by internet users.

The web host installs, secures, and keeps web servers up to date, and develops the underlying technical infrastructure according to users' needs. A web host isn't involved in the content stored on its servers or in developing the websites hosted there.

Which web host should I choose?

Your website needs to be stored on a web hosting server, so choosing a provider and a package that fits your needs matters. Some plans are sized for personal sites, others for businesses or applications. The risk is choosing a solution that is too small, too expensive, or requires more expertise than you have.

Whether you need a reasonably priced hosting solution for a blog, a complete hosting solution for your business activities, or hosting for developing a mobile app, you can compare each web hosting solution at Gandi.
