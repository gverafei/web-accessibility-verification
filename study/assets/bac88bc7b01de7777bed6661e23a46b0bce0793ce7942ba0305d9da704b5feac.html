Good to know

Frequently asked questions

How do I purchase a domain name?

Choose a name and a domain ending, then register it for a specific period of between one and nine years. You can check availability with the domain search tool; if it is available, you can add it to your cart.

Learn more about registering a domain name.

Who does a domain name belong to?

Registries manage domain endings, and accredited registrars such as Gandi register names for customers. Once registered, a domain name is associated with an owner contact for the registration period.

If a name is unavailable, you can check ownership with the Whois service or look for alternatives with the suggestion tool.

How can I try to recover a domain name that is already taken?

You can use Whois to find available registration and contact information and try to reach the current owner. Whois information may not always be up to date, and privacy rules limit the publication of some personal contact information.

What is a web host?

A web host makes data storage and web servers available to website owners. The host maintains and secures the server infrastructure; it is not involved in the content stored on the servers or in developing each hosted website.

Which web hosting solution should I choose?

The right option depends on your project, budget and technical needs. Gandi offers hosting for a blog, hosting for business projects and VPS hosting for applications and other services.
