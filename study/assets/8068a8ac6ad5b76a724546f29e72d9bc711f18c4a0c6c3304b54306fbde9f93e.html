Good to know

Frequently asked questions

How do I purchase a domain name?

Choose and register a domain name with an ending such as .net, .fr, or .org. A registration is for a specific period of time between 1 and 9 years and can be renewed indefinitely. Check availability with the domain search tool.

Who does a domain name belong to?

Once registered, a domain name is associated with an Owner contact, who holds the domain for a particular length of time. If a name is unavailable, someone else has already registered it. You can check details using the Whois service or search for alternatives with the suggestion tool.

What is a web host?

A web host makes data storage and web servers available to website owners. The host installs, secures, and maintains servers and the technical infrastructure used to make website content available online.

Which web host should I choose?

Choose a hosting package suited to your project, budget, and technical needs. Gandi offers hosting for blogs, business activities, and app development, along with other web hosting solutions.
